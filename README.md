# Lamborghini Luxe Showroom Website

A stylish static website for a Lamborghini car showroom. The project uses HTML, CSS, and JavaScript with multiple car images, a responsive layout, smooth animations, inventory cards, a gallery, and an appointment form.

## Files Included

- `index.html` - Main website structure and content
- `styles.css` - Complete styling, layout, responsiveness, and animations
- `script.js` - Mobile menu, booking form interaction, reserve buttons, and scroll reveal effects

## Features

- Full-screen Lamborghini showroom hero section
- Responsive navigation menu for mobile screens
- Featured car collection cards
- Multiple Lamborghini images
- Showroom experience section
- Image gallery
- Appointment booking form
- Smooth scrolling
- Scroll reveal animations
- Mobile-friendly design
